# 常见问题
## 使用操作类
### 怎么打开菜单？
两种方式：
1. **工具物品**：用「⚙ 建造助手 · 菜单」右键点任意方块（创造模式 `/ca tools` 领取，或创造物品栏"装备"分类）；
2. **指令**：`/ca` 、`/call` 、`/ca menu` 任选其一。

> 3.x 之前用"钟"等原版物品做快捷键；4.0.0 起统一为插件自带的 `call:*` 工具物品，原版物品不再触发。

### 怎么获取工具？
创造模式输入 `/ca tools`，或从创造物品栏"装备"分类里取；`/ca tools list` 看功能，`/ca tools debug` 查绑定状态。

### 怎么选区？
1. 方法一：A点B点选择工具  
获取快捷键 `A点选区工具` 和 `B点选区工具`，使用A点工具点击方块选取A点，使用B点工具点击方块选取B点。

2. 方法二：AB轮换选择工具  
获取快捷键 `选区工具`，第一次点击方块选取A点，第二次点击方块选取B点。

### 选区中，可以点击选A点，破坏选B点吗？
可以在 `设置->快捷键设置` 将同一个快捷键的右键模式设置为选A点，左键模式设置为B点

### 怎么清除选区？
1. 菜单 → 选区 → 清除选区；
2. 或指令 `/ca area cancel`。

## 后台管理类
### 怎么让所有人都能使用CALL？
修改[配置文件](user/config)的permission项为"all"，修改后在后台输入指令 `ca r` 或 `call reload` 重新加载CALL即可

### 怎么让一部分人能使用CALL？
1. 步骤一：
修改[配置文件](user/config)的permission项为"customize"，修改后在后台输入指令 `ca r` 或 `call reload` 重新加载CALL。

2. 步骤二：后台输入 `/call add "玩家名"` 添加，`/call ban "玩家名"` 移除

### 怎么导出结构？
1. 使用 `/call list` 命令查看需要导出结构的id
2. 在后台输入指令：`call export <格式名> <结构id> [是否包含实体] [文件名称]` 即可将CALL中保存的结构导出 
3. 在 `plugins/CALL/data/export` 目录下可找到导出后的文件

指令说明：
- `格式名` 目前支持的格式有: mcstructure
- `结构id` 一串字符组成的id
- `是否包含实体` 可不输入，默认为false
- `文件名称` 导出后文件的名称，可不输入，默认为结构id

### 怎么导入文件为结构？
1. 将需要导入的文件放入 `plugins/CALL/data/import` 目录下
2. 在后台输入指令：`call import <文件名> <玩家名> [是否包含实体] [结构名称]` 即可将文件导入为结构给某个玩家

指令说明：
- `文件名` 需要导入文件的名称（需要输入后缀名），目前支持的格式有: mcstructure
- `玩家名` 一个使用过CALL的玩家的玩家名，导入后会将结构加入到该玩家的保存中
- `是否包含实体` 可不输入，默认为false
- `结构名称` 结构的名称，默认为当前时间

### 怎么在另一个存档使用保存的建筑？
结构文件保存在 `plugins/CALL/data` 里，与存档无关；换存档不会丢建筑，直接使用即可。

### 怎么更新CALL？
4.0.0 **没有自动更新**（`autoUpdate` / `updateFrom` 两个键已删除），一律手动覆盖：

1. 到 [Releases](https://github.com/owoser/CALL/releases/latest) 下载最新的 `CALL-<版本>.zip`
2. 解压覆盖 `plugins/CALL` 里的程序文件
3. **保留** `plugins/CALL/data`（配置、玩家设置、已保存的结构都在里面）
4. 重启服务器

## 3.x 常见问题

### 填充 / 清除 / 撤销大区域时卡很久，正常吗？
正常。大区域第一次操作需要让服务端**生成**区块（可能要几秒到几十秒），并且逐块写回时会分批让出主线程（服务器不会卡死）。期间会显示百分比进度。

### 提示"区域超出已加载范围"怎么办？
说明选中的区块还没加载。3.x 会用 `/tickingarea` 自动加载，但如果服务器把 `chunkLoader` 设成了 `none`，或者 `chunkLoadTimeout` 太小，就会失败。把超时调大（例如 30000）后重试。

### 撤销提示"撤销未完成，快照已保留"？
表示有分片恢复失败，**快照没有被删除**，可以再执行一次撤销重试。常见原因是区域太大超出了 `maxRestoreBlocks`，或区块没加载。

### 粘贴出来会不会保留箱子里的东西？
不会。结构只保存方块的类型与状态，**方块实体内容（箱子物品、告示牌文字）不会被复制**，含水方块也会变干。不过覆盖一个仍装有物品的容器前会先清空，所以**物品不会掉在地上**。详见[已知限制](user/known-limitations.md)。

### 进度条 / boss 条去哪了？
粘贴与预览的进度显示方式由配置决定：
- `previewCountdownHud`：`auto` / `hud`（动作栏） / `bossbar`（Boss 条）；
- `displayProgressBar`：每个玩家自己的开关。

> 1.x 的 boss 条因颜色越界会踢客户端；该问题已修复，4.0.0 起可以放心选 `bossbar`。
