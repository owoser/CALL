# 工具物品

3.2.0 起，CALL 自带一套工具物品，**不用记指令**也能完成"选区 → 复制 → 预览 → 粘贴"。

!> 这些物品是插件自带 addon（行为包 + 资源包）定义的自定义物品，id 是 `call:xxx`，
**不占用任何原版物品**，所以不会和别的插件抢物品、也不会被别人的数据包改掉。

## 怎么获得

```text
/ca tools
```

- **只能在创造模式领取**（物品没有合成表，生存拿不到）；
- 也可以在创造物品栏的"装备"分类里找到；
- `/ca tools list` 看每个工具的功能，`/ca tools status` 看物品包是否生效。

首次启动插件会**自动把物品包装到服务端**并写入世界包列表，然后提示：

```text
[CALL] 内置工具物品已安装（19 个文件，已写入世界包列表），重启服务器后生效
```

**重启一次服务器**后物品才存在，之后启动会打印 `[CALL] tool items ready`。

## 五个工具

| 工具 | 左键 | 右键 | 说明 |
|---|---|---|---|
| ⚙ 建造助手 · 菜单 | — | 打开主菜单 | 等同于 `/ca` |
| 选区魔杖 | 设 **A** 点 | 设 **B** 点 | 拿着它**不会破坏方块**，也不会放置方块 |
| 复制魔杖 | — | 复制当前选区 | 等同于 `/ca copy` |
| 粘贴魔杖 | — | 粘贴到点击的方块 | 等同于 `/ca paste` |
| 预览魔杖 | 换落点 | 设落点 / 再点一次旋转 90° | 潜行 + 右键 = 确认粘贴 |

> 左键在 LSE 里**无法拦截**，所以插件用物品的 `can_destroy_in_creative: false` 加上
> `onDestroyBlock` 取消破坏做双保险 —— 拿工具挖方块不会真的挖掉。

## 预览怎么用

3.3.0 起预览会**真的把方块画出来**（客户端可见，不写世界）：

```text
1. 选区魔杖：左键 A 点、右键 B 点
2. 复制魔杖：右键复制
3. 预览魔杖：右键点方块 —— 目标位置出现【真方块 + 蓝色线框 + 尺寸/角度标签】
4. 再右键 = 旋转 90°（方块和线框一起转）；左键 = 换个落点
5. 潜行 + 右键 = 确认，按预览的朝向真正粘贴
```

也可以全用指令：

| 指令 | 作用 |
|---|---|
| `/ca preview set [x y z]` | 设落点（不给坐标就用脚下） |
| `/ca preview rotate` | 旋转 90° |
| `/ca preview mirror` | 切换镜像：none → x → z → xz |
| `/ca preview confirm` | 确认粘贴 |
| `/ca preview cancel` | 取消预览（同时清掉已生成的方块） |
| `/ca preview mode ghost\|wireframe` | 切换"真方块"或"只线框"，写入配置 |
| `/ca preview info` | 看当前生成数量、上限、缩放 |
| `/ca preview calib` | 校准：在 5 个 1×1×1 线框里摆不同 `offY` 的石头，挑刚好填满的那个 |
| `/ca preview calib <数字>` | 把挑中的 `offY` 直接写进 `configs.json` 并重建预览 |
| `/ca tools debug` | 点工具没反应时用：打印手持物品、显示名、左右键命中哪条绑定、物品包状态 |

预览 **60 秒**没操作会自动取消（`previewTimeout` 可改）。

## 方块姿态是按文档参数来的

预览用的是 `itemDisplayCreateSeamless`，姿态取库文档里方块模式的官方示例：

| 参数 | 值 | 说明 |
|---|---|---|
| 位置 | `x+0.5, y, z+0.5` | 方块的**底面中心**（y 是整数） |
| `offY` | `-4` | **模型单位**（16 = 1 格），不是格 |
| `rotX` / `rotZ` | `180` / `180` | 方块模式的必需姿态 |
| `scale` | `0.5` | 文档建议值，可用 `/ca preview calib` 校准 |
| `mode` | `2` | 强制立体方块渲染，创建时一次成型（先建再改会重建，姿态可能被重置） |

方块模式还有一层库内部的**二段变换**（`itemDisplaySetExtend`，默认 `scale=1, rx=-90, ry=0`），我们保持默认不动。

## 预览的性能与上限

一个方块 = 一个展示对象，所以做了三层保护：

| 保护 | 说明 |
|---|---|
| **表面剔除** | 只画能看见的方块（六面都被挡住的内部方块直接丢弃）。实心 20×20×20 从 8000 个降到约 2400 个 |
| **数量上限** | `previewMaxBlocks`（默认 2000）。超过就不画方块，只画线框并提示 |
| **分批生成** | 每 tick 生成 `previewBatchSize`（默认 200）个，带进度提示，随时可取消 |

另外每个展示都设了 `previewViewDistance`（默认 64 格）视距，并且**只有预览者本人能看到**，别人不受影响。

## 预览的局限

!> **看不见方块状态**。展示用的是物品模型，没有 block states：
>
> - 对的：方块种类、位置、大小、整体旋转朝向
> - 不对的：台阶朝哪边、半砖上/下半、栅栏连接、火把方向 —— 都会显示成默认状态

所以预览是"**这个位置放什么方块**"的准确示意，细节朝向以真正粘贴后的结果为准（不满意 `/ca undo`）。

## 假方块是怎么发出来的

用的是 **HologramLib 的 itemDisplay**（服务端发物品展示包）：

- 只让客户端看到，**服务端不产生实体、不写存档**；
- 玩家重连由库自动补发，服务端重启后展示自然消失，不需要清理残留；
- 我们只按自己的 id 逐个 `Destroy`，**从不调 `DestroyAll`**，不会误删别的插件的展示。

（之前我说"做不到"是因为只查了 DebugShape —— 那个只能画无贴图几何体；
itemDisplay / sulfur 这两个域才是画真方块的。）

## 没装 HologramLib 会怎样

- 选区线框自动退回**粒子框**（`areaDisplayMode: wireframe` 时）；
- 预览仍然可用，但**只有线框**，并且会提示"方块预览不可用"；
- 其余工具（菜单、选区、复制、粘贴）**完全不受影响**。

## 改键 / 改绑定

工具走的是和旧快捷物品完全相同的绑定系统：

```text
/ca tool bind   拿着物品执行，把自己的手持物品绑到指令
/ca tool list   查看当前绑定
/ca tool unbind 解绑
```

默认绑定写在 `configs.json` 的 `default.items` 里，按**物品 id** 匹配
（例如 `call:wand_select`），所以玩家自己改过的绑定不会被更新覆盖。
